# คู่มือการสร้างแมพมินิเกม (Map Builder Wiki)

คู่มือนี้รวบรวมข้อมูล "การวางบล็อกสัญลักษณ์ (Marker Blocks)" สำหรับระบบ **MapBuilder / MapParser** เพื่อให้ Builder สามารถสร้างแมพได้อย่างถูกต้องโดยไม่ต้องเข้าไปแก้ไฟล์ Config ด้วยตัวเอง ระบบจะทำการสแกนบล็อกเหล่านี้และแปลงเป็นจุดเกิดหรือลูกเล่นต่างๆ ในเกมโดยอัตโนมัติ

> [!IMPORTANT]
> กฎเหล็กของ Builder: บล็อกสัญลักษณ์ทั้งหมด (ขนแกะ, แป้นเหยียบ, ป้าย, ฟองน้ำ) จะ **ถูกลบทิ้งกลายเป็นอากาศ** อัตโนมัติเมื่อเซิร์ฟเวอร์ทำการสแกน (Parse) ผู้เล่นจะไม่มีทางเห็นบล็อกพวกนี้ตอนเล่นจริง

---

## 1. การกำหนดขอบเขตแมพ (Map Boundaries)
ทุกแมพจะต้องมีการกำหนดขอบเขต (Bounding Box) เพื่อใช้สร้างกระจกกั้นขอบโลก หรือป้องกันผู้เล่นเดินออกนอกเขต
* **วิธีวาง:** วาง **แป้นเหยียบทอง (Light Weighted Pressure Plate - ID 147)** บน **ขนแกะสีขาว (White Wool)**
* **จำนวน:** วาง 2 จุด ตรงมุมทแยง (Corner A และ Corner B) คลุมทั้งแมพ

---

## 2. การตั้งจุดเกิดของทีม (Team Spawns)
ในมินิเกมที่มีการแบ่งทีม Builder จะต้องวางจุดเกิดให้แต่ละทีมตามสีของขนแกะ
* **วิธีวาง:** วาง **แป้นเหยียบทอง (Light Weighted Pressure Plate - ID 147)** บน **ขนแกะสีต่างๆ**
* **ตารางสีทีม:**
  * `Red Wool` = ทีม Red
  * `Blue Wool` = ทีม Blue
  * `Yellow Wool` = ทีม Yellow
  * `Lime Wool` = ทีม Green
  * `Orange Wool` = ทีม Orange
  * `Pink Wool` = ทีม Pink
  * `Cyan Wool` = ทีม Cyan
  * `Purple Wool` = ทีม Purple
  * `Light Gray Wool` = โหมด Solo / ผู้เล่นทั่วไป (ไม่มีทีม)

> [!TIP]
> ในเกมแนว Solo อย่าง Survival Games หรือ Skywars ให้ใช้ขนแกะสีที่กำหนดไว้เป็นจุดเกิดผู้เล่นแต่ละคนได้เลย (มักใช้ Light Gray หรือสลับสีกันไป)

---

## 3. ลูกเล่นเฉพาะมินิเกม (Game Data Points)
แต่ละมินิเกมจะมีลูกเล่นไม่เหมือนกัน เช่น จุดเกิดกล่อง, จุดวางธง ฯลฯ ระบบจะอ่านค่าเหล่านี้จากแป้นเหยียบเหล็ก
* **วิธีวาง:** วาง **แป้นเหยียบเหล็ก (Heavy Weighted Pressure Plate - ID 148)** บน **ขนแกะสีต่างๆ**

นี่คือสีขนแกะและ `DATA_NAME` ที่มินิเกมยอดฮิตใช้งาน:

### ⚔️ Survival Games / Skywars
* **กล่องสมบัติ (Chest):** แป้นเหล็ก + ขนแกะตามสี (Chest ธรรมดา)
* **กล่องตรงกลาง (Mid Chest):** แป้นเหล็ก + ขนแกะตามสี (จุดรวมกล่องของดีตรงกลาง)
* *(สีของขนแกะอาจจะถูก map เข้ากับระดับของ Chest ในโค้ดอีกที แนะนำให้สอบถาม Dev ว่าแต่ละ Tier ใช้สีอะไร)*

### 🎂 Cake Wars
* **จุดวางเค้ก (Cake):** วางป้ายบนฟองน้ำ พิมพ์คำว่า `CAKE`
* **จุดเกิดแร่ (Emerald/Diamond):** แป้นเหล็ก + สีขนแกะ (เช่น Emerald ใช้สีเขียว, Diamond ใช้สีฟ้าคราม)
* **NPC ร้านค้า:** วางป้ายบนฟองน้ำ พิมพ์คำว่า `NPC_SHOP`

### 🛡️ Champions (Domination / CTF)
* **จุดยึดธง (Capture Point):** แป้นเหล็ก + ขนแกะ (มักใช้สี ขาว, ดำ, หรือเทาเพื่อเป็นจุดยึด)
* **ธง (Flag):** ป้าย+ฟองน้ำ พิมพ์ `FLAG_RED` / `FLAG_BLUE`

### 🏗️ Master Builders / Speed Builders
* **จุดเกิดตรงกลางของคนต่อบล็อค:** แป้นทอง + ขนแกะสี Light Gray
* *(เกมนี้มักจะตัดเขตให้เองจากขอบเขตทีม)*

### 🔫 Minestrike
* **จุดวางระเบิด (Bomb Site A / B):** ป้าย+ฟองน้ำ พิมพ์ `BOMB_A` หรือ `BOMB_B`
* **จุดซื้อของ (Buy Zone):** แป้นเหล็ก + ขนแกะสีทีม (Red/Blue)

## 4. จุดพิเศษและตั้งชื่อเฉพาะ (Custom Locations)
สำหรับจุดที่ไม่มีในขนแกะ หรือเป็นลูกเล่นเฉพาะเจาะจงมากๆ Builder สามารถใช้ "ป้าย" เพื่อตั้งชื่อจุดนั้นๆ ได้เลย
* **วิธีวาง:** วาง **ป้าย (Sign)** ไว้ด้านบนหรือติดข้างๆ **ฟองน้ำ (Sponge)**
* **การเขียนป้าย:** บรรทัดที่ 1-4 จะถูกจับมารวมกันเป็นชื่อ (เช่น พิมพ์ `PARKOUR` และบรรทัดสอง `_START` จะได้ `PARKOUR_START`)
* **พิกัดที่ได้:** เซิร์ฟเวอร์จะยึดเอา **บล็อกที่อยู่ใต้ฟองน้ำ** เป็นจุดศูนย์กลางของพิกัดนั้น (ดังนั้นฟองน้ำและป้ายจะถูกลบหายไป เหลือแต่บล็อกพื้นปกติ)

**ตัวอย่างการใช้ป้าย+ฟองน้ำ ที่เจอบ่อย:**
* `HOLOGRAM` - จุดสปอนโฮโลแกรมลอยฟ้า
* `BOSS_SPAWN` - จุดบอสเกิดในเกมแนว PVE
* `SPECTATOR` - จุดเกิดของคนดู (ตายแล้วไปเกิดจุดนั้น)

## 5. ทริคสำหรับ Builder
1. **เรื่องของใบไม้ (No-Decay):** สร้างต้นไม้ไปได้เลย ไม่ต้องกังวลว่าใบไม้จะร่วงตอนผู้เล่นเล่น เพราะตอนสแกนแมพ เซิร์ฟเวอร์จะแปลงใบไม้ทุกบล็อก (ID 18, 161) ให้เป็นแบบ "ไม่ร่วง" (บวก Data Value ขึ้น 4) ให้อัตโนมัติ
2. **ห้ามลืมขอบเขตแมพเด็ดขาด:** ถ้าไม่วาง แป้นทอง+ขนแกะขาว 2 จุด ระบบจะล็อกพิกัดที่ `(-256 ถึง 256)` ซึ่งทำให้แมพมีขนาดใหญ่และอาจกินทรัพยากรมากเกินไป
3. **ใช้ MapBuilder Plugin (เวอร์ชันปัจจุบัน):** ปลั๊กอินรุ่นใหม่ของ Houzicore (MapBuilder) รองรับทั้งการโหลด `WorldConfig.dat` เก่า และสร้าง `schema.json` ใหม่ พร้อมมี GUI บล็อกสวยงามโชว์ให้เห็นว่าจุดไหนคืออะไร สามารถใช้โหมด Edit ภายในเซิร์ฟได้เลย
